DanEQ

A btop-style equalizer, effects rack and audio visualizer for your terminal. It sits in the audio path, so the faders change what you hear, and a built-in self-test proves the filters match the curve on screen.

Install Read the docs Source
daneq --demo music --no-output
10-band EQ | 11 effects | 11 views | 20 themes | 60 fps | braille everything

What you get

Real equalizer

4, 6, 8 or 10 bands, +/-12 dB, preamp, A/B bypass, presets, auto headroom. RBJ biquads in real time. Export to Equalizer APO.

Effects rack

Compressor, overdrive, bitcrusher, megaphone, phaser, flanger, chorus, tremolo, echo, reverb, widener, with braille rotary knobs.

11 visualizations

Spectrum with 6 styles, waterfall, scope, vectorscope, radial, spinning vinyl, reel-to-reel tape deck, fire, starfield, ripples, matrix.

Nerd mode

btop-style audio process, stream and device monitor for Linux engineers.

Test signals

Synthesized animals, cartoon effects, bullhorn, binaural beats, dial-up, public domain tunes like Amazing Grace, and real NASA, FDR and JFK clips.

Runs where you work

Linux (PulseAudio, PipeWire, ThinLinc), macOS (BlackHole), Docker. No root, no kernel modules.

Install

pipx install daneq
daneq --selftest
daneq --demo pink --no-output
git clone https://github.com/fourzerosix/DanEQ.git && cd DanEQ
scripts/install.sh

daneq
docker run -it --rm fourzerosix/daneq --demo --no-output
# or from GitHub's registry:
docker run -it --rm ghcr.io/fourzerosix/daneq --zoo --fx reverb --no-output

Try these

daneq --pink --no-output                 # boost a band, watch the spectrum bulge
daneq --zoo --fx reverb --no-output      # every animal, with reverb
daneq --grace --view vinyl --theme gold  # Amazing Grace on a spinning record
daneq --binaural --beat alpha --view vectorscope
daneq --clip moon --view scope           # Apollo 11, one small step
daneq --nerd                             # audio processes, streams, devices
